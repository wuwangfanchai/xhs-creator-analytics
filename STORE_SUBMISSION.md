# Extension Store Submission Checklist

## Before submitting

- Test the unpacked extension in the latest stable Edge and Chrome.
- Replace the contact placeholder in `PRIVACY.md`.
- Publish the privacy policy at a stable public HTTPS URL.
- Prepare a store description, screenshots, support URL, and category.
- Ensure screenshots and packages contain no private creator data, cookies, tokens, or captures.
- Review Xiaohongshu's current terms before public distribution.

## Package

Zip the files inside the extension directory so that `manifest.json` is at the archive root.

## Microsoft Edge Add-ons

1. Register for the Microsoft Edge program in Partner Center.
2. Create an extension submission and upload the store ZIP.
3. Complete properties, age rating, listing, privacy information, markets, and submission options.
4. Submit for certification and respond to review feedback.

## Chrome Web Store

1. Register a Chrome Web Store developer account.
2. Create an item in the Developer Dashboard and upload the store ZIP.
3. Complete the listing, privacy practices, distribution, and test instructions.
4. Submit for review.

## Reviewer test instructions

Reviewers need a valid Xiaohongshu creator account. After login, open `https://creator.xiaohongshu.com/new/note-manager`, click the extension icon, and click “启动分析面板”. Explain that the extension sends no data to a developer server and generates XLSX locally.
