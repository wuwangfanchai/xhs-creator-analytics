# Privacy Policy

Last updated: September 2, 2026

XHS Creator Analytics processes creator-note data locally in the user's browser to display analytics and generate an XLSX export requested by the user.

## Data handling

- The extension does not collect, transmit, sell, or share user data.
- The extension does not operate a developer-controlled server.
- The extension does not request or store account passwords.
- The extension uses the user's existing authenticated session on `creator.xiaohongshu.com`.
- Note data and results are held only in the current page's memory and are cleared when the page is closed or refreshed.
- XLSX files are created locally and downloaded only when the user clicks the export button.

## Permissions

The extension requests access only to `https://creator.xiaohongshu.com/*` and the active browser tab. These permissions run the analytics interface on the creator note-management page.

## Third-party service

Use of the Xiaohongshu creator platform remains subject to Xiaohongshu's terms and privacy policy. This project is independent and is not affiliated with or endorsed by Xiaohongshu.
